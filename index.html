Each one builds on the last. Each has a runnable demo and at least one honest lesson.

    Multi-turn chatbot & the context window

    A chatbot in a terminal — and the realization that a model has no memory at all. "Memory" is just resending the whole conversation every call.

    Structured output & prompt engineering

    A code reviewer that returns strict JSON, not prose — and why a prompt is only ever a strong nudge, never a guarantee.

    A dev assistant that reads files and searches code. The model only requests a tool; my code is what actually runs it.
